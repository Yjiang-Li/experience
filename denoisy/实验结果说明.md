# 图像去噪实验结果说明

本实验以小猫图像作为清晰图像 `x`，加入高斯噪声 `n`，得到观测图像：

```text
y = x + n
```

实验分别采用两种方法恢复图像：

1. **DCT 域软阈值迭代去噪**：在 DCT 变换域中对系数进行软阈值处理，抑制高频噪声。
2. **ADMM-TV 去噪**：在 TV 域构造正则项，通过 ADMM 迭代降低噪声并保持边缘。

主要输出结果：

- `noisy_image.png`：加入高斯噪声后的图像。
- `dct_soft_threshold_denoised.png`：DCT 域软阈值去噪结果。
- `admm_tv_denoised.png`：ADMM-TV 去噪结果。
- `comparison_grid.png`：原图、噪声图和两种恢复结果对比。
- `convergence_objective.png`：目标函数收敛曲线。
- `convergence_psnr.png`：PSNR 收敛曲线。

一般而言，DCT 软阈值方法实现简单，能明显减弱随机噪声；ADMM-TV 方法更强调图像分段平滑和边缘保持，但可能带来一定平滑效果。通过收敛曲线可以观察两种算法在迭代过程中目标函数下降、PSNR 逐步提高的趋势。
