# 压缩感知仿真实验结果说明

本实验构造 `A ∈ R^{300×1000}` 的高斯随机观测矩阵，生成长度为 `1000`、稀疏度为 `35` 的随机稀疏信号 `x`，并加入标准差为 `0.01` 的高斯噪声，得到观测值：

```text
y = A x + n
```

实验分别采用迭代阈值算法（ISTA）和 ADMM 算法求解 L1 正则化恢复问题：

```text
min_x 0.5 ||Ax-y||_2^2 + lambda ||x||_1
```

其中 `lambda = 0.03`，ADMM 参数 `rho = 1.0`，最大迭代次数为 `250`。

生成的三张主要图片为：

1. `convergence_objective.png`：比较 ISTA 与 ADMM 的目标函数收敛过程。
2. `convergence_relative_error.png`：比较两种算法相对恢复误差随迭代次数的变化。
3. `signal_reconstruction.png`：展示真实稀疏信号与两种算法恢复结果的对比。

通常可以观察到：ADMM 在前期下降速度较快，迭代阈值法实现更简单但收敛速度相对较慢。两种方法都能恢复主要非零位置，但在含噪声条件下，恢复结果会存在一定幅值偏差和少量残余误差。
